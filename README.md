# Edirne Hava Durumu v3

Android uygulaması MGM'nin Edirne saatlik tahmin sayfasından veriyi arka planda alır ve veriyi kendi arayüzünde gösterir. MGM sayfası WebView olarak gösterilmez.

Kaynak: https://www.mgm.gov.tr/tahmin/saatlik.aspx?m=EDIRNE

## APK
GitHub Actions ile `gradle assembleDebug` çalıştırılır. Actions > Build APK > Artifacts bölümünden APK indirilebilir.
